#!/bin/bash

# Update package list
sudo apt update

# Install Java (required for Maven)
sudo apt install -y openjdk-17-jdk

# Install Maven
sudo apt install -y maven

# Verify installation
mvn -version
How to use it
Save it as install_maven.sh

Make it executable:

chmod +x install_maven.sh

Run it:

./install_maven.sh
Optional: Check installed versions

After installation:

java -version
mvn -version
